# ReWild Wicklow Dashboard

Dash web application for viewing ReWild Wicklow project sites, planting areas, visit history, and photographs. The interactive map is exported from QGIS with qgis2web and then patched by the scripts in this repository.

## Requirements

Install these separately before starting:

- [Miniconda](https://docs.conda.io/projects/miniconda/en/latest/) or another Conda distribution
- QGIS
- The **qgis2web** QGIS plugin
- Access to the ReWild Wicklow project in Mergin Maps

Python dependencies are managed with `environment.yml`.

## First-time setup

### Dependencies
From the repository root:

```bash
conda env create -f environment.yml
conda activate rewild_dashboard
```

To confirm that the environment is active:

```bash
python --version
```

The project uses Python 3.11.

If `environment.yml` changes later, update the existing environment with:

```bash
conda env update -f environment.yml --prune
```
### Environment Variables
 Create the following `.env` file in the project root
```env
BASIC_AUTH_USER=user
BASIC_AUTH_PASSWORD=password
```


## Run the dashboard

From the repository root:

```bash
conda activate rewild_dashboard
gunicorn app:server
```

Open the local address printed in the terminal. Gunicorn normally uses `http://127.0.0.1:8000/`.

## Update the map from Mergin Maps

The short version is:

1. Download the latest Mergin Maps project.
2. Open `projects.qgz` in QGIS.
3. Export the project with qgis2web as a Leaflet map to `src/assets/`.
4. Rename the exported folder to `qgis-map`.
5. Rebuild the photo index.
6. Run `src/scripts/update_html_export.py`.
7. Start the Dash app and check the result.

Full instructions are in [`docs/UPDATE_MAP.md`](docs/UPDATE_MAP.md).

## Important generated files

`src/assets/qgis-map/` is generated by qgis2web and then modified by `update_html_export.py`. Do not make important manual changes inside the generated export unless the same change is also added to the patch script; a future QGIS export can overwrite them.

Custom marker assets are kept in `src/assets/markers/`. `update_html_export.py` copies the SVG files it needs into the current qgis2web export.
